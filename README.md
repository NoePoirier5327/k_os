# KOs
A 64 bit kernel written in rust.<br>
The name k in the name stands for kijetesantakalu and it is pronounced chaos.

## Documentation
Any question about the project, see [here](https://github.com/NoePoirier5327/k_os/blob/master/documentation.md).

## Building the project
To build the project for the x86_64 architecture, you have to set the cargo compiler as nightly, download the `grub-efi` and `grub-bios` dependencies and then use the `make` command. <br>
To run the project you can use the `make run` command. If you want to have the emulator's log, you can use the `make run-log` command.
